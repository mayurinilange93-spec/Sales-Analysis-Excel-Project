# 📊 Sales Analysis Using Microsoft Excel

## 📌 Overview

Sales Analysis is a data analytics project focused on exploring sales transaction data and extracting meaningful business insights using Microsoft Excel.

The project involves analyzing revenue performance, performing date-based calculations, and solving business-oriented analytical questions through Excel formulas and functions.

## 🎯 Objectives

- Analyze sales transaction data.
- Calculate total and cumulative revenue.
- Evaluate sales performance across different time periods.
- Perform date-based and conditional calculations.
- Derive meaningful insights from sales data.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and calculations
- **Excel Functions** – Formula-based analysis

## 📈 Analysis Performed

- Revenue Analysis
- Cumulative Revenue Analysis
- Date-Based Sales Analysis
- Conditional Aggregation
- Sales Performance Evaluation

## 🧮 Excel Functions Used

- `SUM()`
- `SUMIFS()`
- `COUNTIFS()`
- `IF()`
- Date-based criteria and calculations
